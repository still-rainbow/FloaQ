# 바닥 좌우 회전 모듈 V0.1

FloaQ / A208 · 2026-08-31 · 단위 mm

**발사장치, 발사체, 스프링 사출부, 위아래 각도 조절부를 제외한 별도 설계다.** 기존 `spring_launcher_v01`과 `design` 폴더는 변경하지 않았다.

!조립 미리보기 (`preview/assembly.png`, 공개 사본 미포함)

## 어떻게 움직이나

아래 받침과 모터는 고정되고 **원형 상판만 수직축을 중심으로 좌우 회전**한다. 상판은 금속 턴테이블 베어링으로 받치고, 서보는 혼에 연결한 작은 구동판의 돌기 두 개로 회전력을 전달한다. 구동 돌기와 상판 사이에는 축방향 여유를 두어 상판을 서보 축으로 끌어당겨 고정하지 않도록 했다.

이번 설계는 **MG996R 크기의 위치제어 서보**를 기준으로 한다. 사용자의 실제 모터가 정해지지 않았으므로 모터·혼·베어링 실측 후 장착부를 최종 확인해야 한다. 연속회전 서보를 동일하게 사용할 수는 없다. 제어 초기 목표 범위는 **좌우 ±45°**이며 실제 각도와 PWM의 관계는 보정해야 한다. 자동 발사 기능이나 제어보드/펌웨어는 포함하지 않는다.

## 크기와 인터페이스

| 항목 | 설계값 |
|---|---|
| 고정 바닥 | Ø180 × 바닥 두께 6 |
| 회전 상판 | Ø160 × 평판 두께 8 |
| 설치면에서 상판 윗면까지 | 77 |
| 고정 베어링 받침 | 132 × 132 × 8, 설치 높이 52 |
| 금속 턴테이블 베어링 | 4인치급, 모델링 높이 9, 체결 구멍 81 × 81 |
| 베어링 중앙 통과 공간 | **최소 Ø50 필요**. 실제 내부 형상도 확인 |
| 상부 장비 체결 | M4 관통 구멍: 60 × 60 또는 100 × 100 정사각 패턴 |
| 시험판 고정 | 중심 반경 82의 네 방향, Ø5.5 구멍 |
| 초기 제어 범위 | 좌우 ±45° 목표; 기구 외곽 회전 여유와 서보 가동 범위는 별개 |
| 출력판 가정 | FDM 220 × 220, 0.4mm 노즐 |

상판 구멍은 범용 패턴이며 이전 발사장치와 바로 맞는다고 보장하지 않는다. 실제 올릴 장비에 맞춰 어댑터를 추가하거나 상판 구멍을 수정한다. 상부 장비 질량·무게중심·반력은 아직 주어지지 않았으므로 **허용 탑재 질량이나 각도 정확도를 보증하지 않는다.**

## 출력 파일

핵심 조립 부품은 **5종**이고, 조정용 심과 시험편까지 STL 7종이다.

| 파일 | 수량 | 출력 방향 |
|---|---:|---|
| `01_fixed_base.stl` | 1 | 큰 원형 바닥을 아래로, 기둥은 위로 |
| `02_bearing_carrier.stl` | 1 | 넓은 평면을 아래로 |
| `03_servo_cradle.stl` | 1 | 평평하게. 기준 MG996R용 원형 M3 장착 구멍과 몸통 개구부 사이의 최소 벽은 1.6mm다. 슬롯이 아니므로 실제 서보 구멍 위치를 먼저 확인한다. |
| `04_rotating_top.stl` | 1 | 파일 방향 그대로. 실제 윗면이 출력판에 닿고 아래쪽 연결 보스가 위로 자람 |
| `05_floating_drive_dog.stl` | 1 | 작은 원판을 아래로, 두 돌기가 위로 |
| `06_alignment_shim_1mm.stl` | 필요 시 4 | 1mm 심. **기본 조립에는 넣지 않는다** |
| `07_fit_coupon.stl` | 1 | 구멍·너트 끼움 시험용 |

시작 출력 설정: PETG, 층 0.2mm, 벽 4줄 이상, 상하 각 5층 이상, 인필 35~45%. 이는 강도 인증 설정이 아니다. 작은 구동 돌기는 슬라이서에서 충분한 벽과 내부 충전이 생기는지 확인한다. 실제 장비 탑재 전 빈 상판으로 검증한다. 출력 시간을 줄이려면 시험편 → 구동판/서보 받침 → 큰 부품 순서로 출력한다.

## 별도 구매 부품

수량과 길이는 `BOM.csv`를 참고한다. 실제 나사 머리·와셔·너트 두께에 따라 볼트 길이를 확인한다.

- 위치제어 서보 1개: MG996R 외형 약 40.7 × 19.7 × 42.9mm를 기준으로 공간을 마련했다. 제조사마다 장착 탭과 축 높이가 다를 수 있다. [제조사 사양](https://torqpro.com/product/mg996r/)
- 해당 서보의 **전용 혼과 중앙 고정 나사**. 스플라인은 출력하지 않는다. 구동판의 M2용 슬롯은 중심 반경 7.5~12.5를 허용한다. 대칭인 2개 이상, 가능하면 4개 체결점을 사용하며 혼의 실제 구멍·재질·나사 규격에 맞춘다.
- 금속 턴테이블 베어링 1개. 참고 제품은 [ServoCity 1620-0001-0004](https://www.servocity.com/4x4-ball-bearing-turntable/)이다. 제조사 STEP에서 81mm 정사각 구멍 중심, Ø4.25 구멍과 9mm 높이를 읽어 설계했다. **제품 페이지의 높이 설명(5/16인치)과 STEP 높이(9mm)가 다르므로 실물 우선**이다. 외곽/내부 레이스는 단순화한 참고 형상이다. 다른 100mm급 베어링이 자동으로 호환된다는 뜻은 아니다.
- M3/M4 볼트·너트, 혼용 소형 체결품, 서보용 별도 전원과 제어기.

금속 베어링의 판매 페이지 하중 등급을 이 3D 출력 모듈 전체의 허용 하중으로 사용해서는 안 된다.

## 조립 순서

**처음에는 서보 전원을 연결하지 않는다. 상부 장비도 올리지 않는다.**

1. 시험편으로 볼트·너트 끼움을 확인한다. 휘거나 갈라진 출력물은 교체한다.
2. 바닥 부품 아래에 기둥용 M4 너트 4개, 서보 받침용 M3 너트 4개를 넣는다.
3. 낮은 네 기둥 위에 서보 받침을 M3×40으로 고정한다. 처음에는 1mm 심을 사용하지 않는다.
4. 서보 본체를 받침의 사각 구멍으로 내려 넣고 장착 탭을 M3 체결품으로 고정한다. 실제 서보 탭/고무 부싱에 맞춰 길이를 확인한다.
5. 금속 베어링의 고정측을 회색 베어링 받침에 체결한다. 받침을 높은 네 기둥에 M4×60으로 고정한다. 베어링 레이스를 나사 끝으로 누르지 않는다.
6. 아직 상판과 연결하지 않은 상태에서 서보 중립을 확인한 뒤 전원을 끈다. 혼을 중립 방향으로 장착하고 작은 구동판을 혼에 체결한다. 중앙 나사는 원래 서보용을 사용한다.
7. 상판의 베어링 체결용 M4 너트는 **윗면 포켓**에 넣는다. 베어링 회전측 아래에서 짧은 M4 볼트로 상판을 고정한다. M4×8은 참고 길이이며 나사 끝이 윗면을 넘지 않는지 확인한다.
8. 상판을 조립할 때 두 구동 돌기가 아래 슬롯에 들어가도록 맞춘다. 금속 베어링이 상판을 지지해야 하며 구동판 위에 상판이 얹히면 안 된다.
9. 위쪽 베어링 체결 나사는 상판을 45° 돌리면 받침의 네 Ø10 서비스 구멍으로 접근할 수 있다. 서보의 실제 가동 범위가 부족하면 **혼 연결을 먼저 해제**하고 돌린다. 전원이 꺼져 있어도 서보를 억지로 역구동하지 않는다.
10. 바닥을 별도 시험판에 고정한다. 혼을 분리한 상태로 상판 회전 저항을 확인하고, 서보 축과 베어링 중심을 정렬한다. 다시 연결한 뒤 작은 각도로 무부하 전동 시험한다.

## 가장 중요한 높이 확인

| 접촉/간극 | 명목 CAD 값 |
|---|---:|
| 구동판 평면 위 ↔ 상판 아래 보스 끝 | 3.0 |
| 돌기 끝 ↔ 수용 슬롯 천장 | 3.0 |
| 돌기와 수용 슬롯의 겹침 높이 | 4.0 |
| 돌기 폭 / 슬롯 폭 | 6.0 / 6.8 |
| 베어링 중앙 개구부 / 보스 외경 | 최소 50 / 48 |

실제 혼 높이와 베어링 두께가 달라지면 이 간극도 달라진다. **심을 무조건 추가하면 돌기가 천장에 닿을 수 있다.** 심은 실측상 서보가 낮을 때 네 지지점에 동일하게 쓰는 조정 부품이다. 조립 후에도 돌기 천장과 평면에 각각 최소 1mm 여유를 확보하고 충분한 맞물림을 유지한다. 조건이 맞지 않으면 부품 높이를 원본에서 수정한다.

슬롯 여유 때문에 방향을 바꿀 때 유격이 있다. 정밀 엔코더 회전 스테이지가 아니며, 서보 명령각이 곧 실제 상판각이라는 보장은 없다. 상판 중심 정렬과 낮은 마찰을 확보한 다음 보정한다.

## 제어와 한계

`CONTROL.md`에 전원 분리, 중립 설정, 각도 보정, 소프트웨어 제한의 순서를 적었다. 이번 패키지는 기구 설계이며 보드별 전용 코드나 폐루프 각도 센서는 포함하지 않는다.

- 금속 부품은 참고 형상으로만 렌더링하며 STL 목록에 없다.
- 이번 검사는 출력 메시, 고정/회전 부품을 감싸는 보수적인 외곽 형상 간 간섭, 연결 돌기 맞춤, 단순화한 베어링/서보 외형 확인이다. 회전 외곽을 원통으로 감싸 기구의 회전 여유를 확인하지만, 이것이 서보의 무한 회전을 허용한다는 뜻은 아니다. 글자 각인을 생략하고 원형 해상도를 낮춘 검사 형상을 쓴다.
- 실제 서보 토크, 구동 돌기 강도, 베어링 유격, 반복 수명, 최대 탑재 하중, 각도 정확도, 방수·해상 운용 적합성은 미검증이다.
- 기계식 회전 스토퍼나 독립 안전 인터록은 포함하지 않는다. 소프트웨어 제한만으로 안전성을 보증하지 않는다.
- 상부 장비 배선에 여유를 주고 회전부·틈새에 손이나 케이블이 들어가지 않게 한다. 무한 회전용 슬립링은 없다.

## 파일 수정·재생성

`yaw_base.scad`를 OpenSCAD에서 열면 조립체가 보인다. `yaw`는 미리보기 각도, `exploded=true`는 분해 모습이다. 개별 부품은 `part`를 `frame`, `carrier`, `cradle`, `rotor`, `driver`, `shim`, `coupon`으로 바꿔 볼 수 있다. 파라미터 변경 후 조립 관계와 간섭을 다시 확인한다.

```powershell
python .\build.py --package
```

Python 표준 라이브러리와 OpenSCAD를 사용한다. 다른 OpenSCAD 경로는 `--cad`로 지정한다. 출력 파일은 모두 mm 단위이며 슬라이서에서 개별 STL을 자동 중앙 배치한다.
