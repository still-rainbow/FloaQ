# FloaQ — 구명 부유체 모형 발사기 V0.2

**결론: 본체를 공용으로 설계하고, 자동 해제용 작은 부품까지 첫 출력 묶음에 넣는다.** 처음에는 손으로 잠금 핀을 뽑고, 나중에는 서보·줄·도르래를 부착해 같은 핀을 당긴다. 본체를 다른 버전으로 바꿔 출력하는 업그레이드는 필요 없도록 구성했다.

단, 이것은 **실물 끼움·하중·발사 시험 전의 시제품 CAD**다. 한 번의 출력으로 실물 조립까지 성공한다고 보장할 수 없다. 구매품 치수, 프린터 수축, 줄 마찰을 확인해야 한다. 실제 선박·사람 대상 구조 장치가 아니다.

## 무엇이 달라졌나

| 부분 | 처음 조립 | 자동 해제 추가 후 | 추가 출력 |
|---|---|---|---|
| 본체·데크·슬라이더·플라스틱 링 | 동일 부품 | 그대로 사용 | 업그레이드 때문에 필요하지 않음 |
| 피치, 위아래 조준 | MG996R + 평행 링크 | 그대로 사용 | 없음 |
| 잠금 핀·빨간 안전 핀 | SUS304 Ø6 핀, 손으로 조작 | 잠금 핀만 서보로 당김, 안전 핀은 수동 | 없음 |
| 공용 해제 프레임 | 처음부터 설치 | 그대로 사용 | 없음 |
| 자동 해제 어댑터·릴·도르래·간격 부품 | 미리 출력하고 보관 | 서보·베어링·줄과 함께 설치 | 미리 출력했다면 없음 |
| 스프링 압축·재장전 | 수동 장전 | 여전히 수동 장전 | 자동 장전은 범위 밖 |

모터는 **yaw 1개(보유) + pitch 1개(추가) + 해제 1개(나중에 추가)**다. 보유 MG996R이 배터리 쉴드에서 동작했다는 조건을 유지한다. 다만 세 모터를 함께 구동할 때의 전원 용량까지 확인된 것은 아니다.

## 구조

### 피치 구동

- Ø100 × 10mm 링을 직선 밀대로 밀어내는 방식. 링 내경은 50mm로 가정했다.
- 기존 수동 각도 구멍 대신, 본체 중간의 **독립 Ø6 축 2개 + 626ZZ 베어링 2개**를 사용한다. 가이드 축을 가로지르는 긴 관통 피치 축은 쓰지 않는다.
- 회전축 중심은 본체 뒤에서 82mm, 받침 바닥 기준 높이 85mm다.
- MG996R과 본체의 크랭크 반경은 각각 20mm, 회전 중심 간격 및 연결봉 홀 간격은 50mm다. 0–45°에서 평행 링크가 움직이도록 설계했다.
- 서보 출력축에 본체를 매달지 않는다. 지지대와 금속 축·베어링이 본체를 받치고, 별도 연결봉으로 회전력을 전달한다.
- 기존 yaw 상판의 60×60 / 100×100mm 체결 패턴에 맞는 구멍을 받침에 넣었다. **나사 돌출·회전 간섭·전체 무게중심은 yaw 실물과 합쳐 별도로 확인해야 한다.** 처음에는 평평한 작업대에 고정해서 시험한다.

### 공용 수동/자동 해제

1. 금속 잠금 핀이 데크 → 슬라이더 → 바닥 구멍을 관통해 슬라이더를 잡는다. 반대쪽에는 독립 안전 핀이 있다. 데크 위의 15mm 높이 안내 기둥에 손잡이가 닿아 핀이 더 내려가지 않게 하고, 핀의 초기 높이를 일정하게 만든다.
2. 수동형에서는 공용 손잡이를 위로 당겨 핀을 뽑는다.
3. 자동형은 서보 릴이 비탄성 줄을 감아 도르래를 거쳐 손잡이를 들어 올린다. 서보가 스프링을 직접 압축하거나 장전 하중을 계속 버티지는 않는다.
4. 릴의 명목 감김 반경 16mm에서 140° 회전하면 줄 감김 길이는 약 39.1mm다. **실제 핀 상승 목표는 38mm**이며, 줄 느슨함·매듭·유효 반경 때문에 회전각만 믿으면 안 된다.
5. 핀 하단은 장전 시 z=-1mm, 38mm 상승 시 z=37mm다. 데크 위쪽 z=32mm보다 5mm 높아진다.
6. 발사 후 줄을 느슨하게 하고 사람이 다시 장전한다. 자동 복귀·자동 장전·발사 완료 센서는 구현하지 않았다.

줄은 두 손잡이 구멍에 대칭으로 연결한 짧은 고리로 중앙을 당긴다. 한쪽만 당겨 핀이 기울거나 걸리지 않게 한다. 도르래 회전·줄 이탈·핀 인출력은 실제 부품으로 확인한다. 렌더링의 줄은 **경로 설명용 선이며 유연체 시뮬레이션 결과가 아니다.**

## 출력 횟수 줄이기

### 1차: 작은 실물 확인 묶음

`00_fit_coupon`, `03_slider`, `12_servo_horn_arm`, `18_future_servo_adapter`, `19_future_cable_spool`, `20_future_pulley`를 먼저 출력한다. 이 부품들은 검사 후 본 조립에도 사용한다. 베어링 쿠폰은 시험용이다. 이전에 V0.1 슬라이더를 이미 출력했다면 새로 출력하지 않고 그것으로 검사한다.

- 626ZZ가 19.1 / 19.25 / 19.4mm 중 어느 구멍에 적절히 들어가는지 확인한다.
- 실제 Ø6 축이 슬라이더의 **수평 출력 구멍**을 걸림 없이 통과하는지 확인한다.
- 구매할 MG996R의 몸통, 체결 귀, 축 끝 높이와 동봉 혼의 구멍을 직접 확인한다. 같은 이름의 호환 서보도 치수가 다를 수 있다.
- 인쇄한 혼 연결 부품은 **서보에 동봉된 혼에 나사로 붙이는 부품**이다. 출력한 구멍을 금속 스플라인에 억지로 끼우는 방식이 아니다.
- 623ZZ와 도르래의 끼움, 같은 MG996R 혼과 릴의 체결도 확인한다. 해제용 모터까지 지금 같은 모델로 확보해 두면 나중에 다른 혼/케이스가 배송되는 불확실성을 줄일 수 있다. 이 추가 모터를 당장 설치할 필요는 없다.

### 2차: 나머지 부품을 일괄 출력

확인한 치수를 CAD에 반영한 뒤 나머지 부품과 미래 자동화용 부품을 함께 출력한다. 여기서 '한 번에'는 **출력 의뢰/예약을 묶는다는 뜻**이지, 모든 부품이 한 출력판에 들어간다는 뜻은 아니다. 사용 가능한 프린터와 슬라이서에서 실제 판 수·시간을 확인한다.

| 03 / 04 | 슬라이더 / 밀대 | 각 1 | 슬라이더 재사용, 밀대에는 손잡이 체결 구멍 추가 |

220×220mm 출력판, 0.4mm 노즐을 가정했다. 부품별 외곽 크기는 `qa/meshes.json`에 있다. 기구 부품은 PETG, 0.2mm 층, 벽 4–5줄, 인필 35–45%를 출발점으로 삼되 이는 강도 보증 설정이 아니다. 가로 구멍 처짐과 돌출부 서포트를 슬라이서에서 확인한다. 베어링·핀 구멍에 서포트를 남기지 않는다. 서포트가 필요한 형상을 자동 무서포트 부품으로 간주하지 않는다.

## 조립 순서

1. 스프링을 넣지 않은 상태에서 본체, 슬라이더, 가이드 축, 밀대와 양옆 장전 손잡이를 조립한다. 손잡이는 M3×12와 밀대 아래쪽 매입너트로 고정한다. 볼트 끝이 밀대 아래로 나오지 않아야 한다. 가이드 축은 뒤쪽과 앞쪽 지지대 밖에서 금속 세트칼라로 이탈을 막는다.
2. 626ZZ를 본체 안쪽에서 삽입하고 고정판으로 외륜 이탈을 막는다. 베어링을 세게 눌러 변형시키거나 내·외륜을 동시에 조이지 않는다.
3. 지지대를 받침에 고정하고 SUS304 Ø6×45mm 독립 축을 양쪽에 넣는다. **15번이 설치되는 쪽의 08번 지지대는 M4×35 볼트 2개를 사용해 바깥쪽 15번 수직 레일까지 함께 관통 체결하고, 반대쪽 08번은 M4×25 볼트 2개를 사용한다.** 지지대 절개부를 조여 축을 고정하고, 세트칼라는 축 이탈 방지용으로 배치한다. 회전하는 본체/고정판과 칼라 사이에는 작은 간극을 남긴다.
4. 15번의 좁은 바닥 탭 2개를 07번 받침의 바깥쪽 구멍열(x=18/66, y=-86)에 맞추고 M4×20 볼트 2개로 체결한다. 15번 본체는 08번 및 소켓보다 바깥쪽에 있어야 하며 억지 끼움이나 겹침이 없어야 한다. 이어 피치 서보, 동봉 혼, 출력 크랭크, 연결봉을 설치한다. 금속 M3 볼트와 잠금 너트를 사용하되 조인트는 회전해야 한다. 손으로 걸림이 없는지 확인한 뒤 서보 각도를 제한해 시험한다.
5. 공용 해제 프레임과 두 핀 손잡이를 조립한다. 주 잠금핀과 안전핀도 SUS304 Ø6×60mm를 사용하고, 손잡이 위에 Ø6용 금속 칼라를 고정해 손잡이가 핀을 들어 올리게 한다.
6. 양옆 손잡이를 당기는 무스프링 동작과 두 핀 삽입을 먼저 반복한다. **손잡이는 밀대에 고정되어 함께 움직이며 별도의 탈착 포크는 사용하지 않는다.**
7. 승인된 저하중 스프링과 완충재를 설치하고 받침을 고정한다. 초기 시험은 2인 1조로 한 사람이 양옆 손잡이를 잡고 다른 사람이 두 핀을 끼운다. 핀 체결 후 손잡이에 힘을 서서히 빼서 잠김을 확인한다. **안전 핀 제거는 수거함을 향하고 손과 주변 물건을 가동 범위에서 치운 뒤 마지막에 수행한다.**

## 나중에 자동형으로 전환하는 순서

1. 발사체를 치우고 스프링을 제거하거나 완전히 무부하로 만든다. 전원만 끄는 것으로는 스프링 에너지가 없어지지 않는다.
2. 보관한 18번 어댑터에 새 MG996R을 고정하고 공용 프레임의 두 M3 체결점에 장착한다.
3. 동봉 혼에 19번 릴을 나사로 고정한다. 20번 도르래에는 623ZZ를 넣고 21번 간격 부품과 금속 M3 축 볼트로 프레임에 고정한다. 베어링 내륜은 고정하되 도르래는 자유롭게 회전해야 한다.
4. 비탄성 줄을 연결한다. 스프링 없이 서보 회전 범위를 정하고 **실측 핀 상승 38mm**를 확인한다. 감긴 줄이 겹치거나 도르래 밖으로 빠지지 않도록 한다.
5. 안전 핀을 꽂고 시동/리셋/전원 단절을 시험한다. 초기화 중 임의 서보 이동이 발생할 수 있으므로 부팅 동작을 안전 장치로 믿지 않는다.
6. 수동 핀 인출력이 충분히 작은지 측정한 다음 보호된 시험 구역에서 자동 해제를 시험한다. 걸리는 핀을 더 큰 모터 힘으로 억지로 뽑지 않는다.

## 스프링과 거리 — 아직 확정하면 안 되는 부분

- 목표는 20–60cm지만 CAD만으로 거리를 보장하지 않는다. 링과 밀대 질량, 마찰, 발사 높이, 각도에 따라 달라진다.
- 특히 발사 지점과 착지 지점의 높이가 다르면, 고정된 스프링과 0–45° 피치만으로 20–60cm 전체를 덮지 못할 수 있다. 실측 후 같은 공간에 맞는 저하중 스프링 조건을 조정한다. 임의의 각도-거리 표를 제어 코드에 넣지 않는다.
- 본체의 명목 이동량은 36mm, 완충재 이후 금속이 아닌 하우징의 기하학적 정지 위치는 약 41mm다. **완충재는 필수이며, 하드 스톱에 매번 충돌시키는 장치가 아니다.**
- 스프링 견적 시작 조건은 자유장 약 76mm, 조립 길이 32–68mm, 추가 장전 때 최소 30mm, 내부 공간 외경 최대 14mm다. 스프링 좌석 와셔를 넣으면 길이가 달라지므로 그 두께까지 공급사와 확정한다.
- 후보 강성 0.12–0.20N/mm는 설계 요청 범위일 뿐 확정 부품이 아니다. 예를 들어 0.20N/mm, 자유장 76mm라면 32mm에서 힘 8.8N, 저장 에너지 약 0.194J다. 방출 가능한 32→68mm 구간 에너지는 약 0.187J이며 발사체 에너지와 같지 않다.
- Ø6 가이드와의 간극, 최소 압축 길이, 좌굴, 수평~45° 사용 가능 여부를 공급사에 확인한다. **외경과 길이만 맞는 강한 금형 스프링을 임의로 사지 않는다.**
- 공개 사용 지침에서 수평 사용을 제한하는 MISUMI WY 계열은 이 설계의 확정 부품으로 채택하지 않았다. [해당 제조사 사용 지침](https://us.misumi-ec.com/pdf/press/18e_pr1397.pdf)

## 전원과 제어 범위

권장 연결은 Raspberry Pi → I2C PWM 드라이버 → yaw/pitch/해제 서보다. 보유 배터리 쉴드의 서보 출력은 기존 동작 전압을 유지하고, 모터 여러 개가 움직일 때의 전압 강하와 전류를 실측한다. Pi/Jetson 전원과 서보 부하를 무검증으로 합치지 않는다.

PCA9685 모듈을 쓰면 로직 VCC와 서보 V+를 구분하고 공통 GND를 구성한다. GPIO/3.3V 로직 핀에서 모터 전력을 공급하지 않는다. [제조사 배선 안내](https://learn.adafruit.com/16-channel-pwm-servo-driver/hooking-it-up)

센서 연동, 발사 허가 상태 머신, 비상정지 회로, 원격 자동 발사 코드는 이번 CAD에 포함하지 않았다. 자동형은 기구 장착 대비 설계이며, 현장 자동 운영이 검증됐다는 뜻이 아니다.

## 파일과 검증 범위

- `launcher.scad`: 수정 가능한 원본. `automatic=false/true`로 수동/자동 비교.
- `stl/`: 부품별 STL. **조립체 전체를 한 덩어리로 출력하지 않는다.**
- `preview/`: 실제 CAD 렌더링. 금속부품·서보는 단순화한 참조 외형이다.
- `구매목록.md`: 알리익스프레스 우선 검색 링크, 국내 예비 조달 경로, 추가 수량과 미확인 조건.
- `qa/meshes.json`: STL 닫힘·연결성·외곽 크기 검사.
- `qa/interference.json`: 지정 위치에서 CAD 교차 검사. 피치 받침 검사는 본체/해제 장치/장전 손잡이의 보수적인 외곽 상자를 사용한다.
- `build.py`: STL·검사·미리보기 재생성. 기존 V0.1의 공용 형상과 검사 코드를 읽는다. 압축 파일 내 **두 폴더를 나란히 유지**한다. 기존 V0.1 파일은 수정하지 않았다.

검증은 FDM 수축, 나사 체결 강도, 연속 회전 경로 전체, 실제 서보의 공차, 줄 변형/매듭, 스프링 피로, 핀 인출력, 발사 거리, 침수/부력 성능을 입증하지 않는다. 보호안경과 수거함을 사용하고 사람·동물을 향해 시험하지 않는다.

재생성 예: 작업 폴더에서 `python spring_launcher_v02_modular/build.py export checks renders`.
