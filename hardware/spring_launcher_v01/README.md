# 스프링 직선 사출기 + 플라스틱 부유체 V0.1

FloaQ / A208 — 3D 프린트용 파라메트릭 설계

> **지금 출력해 확인할 수 있는 것은 형상과 무하중 조립이다.** 실제 스프링 제품·강도, 출력물 내구성, 방수·부력, 20~60cm 사거리는 검증되지 않았다. STL 검사 통과는 장치 안전성이나 발사 성능 인증이 아니다. 먼저 **스프링 없이** 조립한다.

## 설계 범위

- 발사체: 플라스틱 링 한 개, 외경 **100mm**, 안쪽 구멍 **50mm**, 전체 두께 **10mm**. 가장자리에 0.8mm 모따기.
- 발사 방식: **압축 스프링 → 하부 슬라이더 → 상부 밀대 → 모형 직선 이동**. 발사 순간 받침이나 회전팔이 움직이는 투석기형이 아니다.
- 스프링·가이드 축(연마봉)·하부 슬라이더는 고정 데크 아래에 수납한다. 상부 밀대의 두 연결부만 데크 슬롯을 통과한다.
- 각도: 양옆 지지대의 **0 / 10 / 20 / 30 / 45°** 구멍에 금속 볼트를 넣어 고정한다. 값은 각도이지 보장 사거리가 아니다.
- 이번 버전: **수동 장전, 두 개의 금속 수직 핀, 수동 해제**. 서보 자동 해제/자동 장전/좌우 조준은 포함하지 않는다. 특정 서보 제품 치수나 토크를 임의로 가정하지 않았다.
- 본체 164×132mm, 받침 바닥 190×180mm. **220×220mm FDM 프린터, 0.4mm 노즐을 가정**했다. 다른 출력판에서는 슬라이서에서 먼저 확인한다.

## 파일

- `launcher.scad`: 수정 가능한 OpenSCAD 원본. 열면 조립 상태가 표시된다.
- `stl/`: 부품별 출력 파일. **조립체 전체를 하나로 출력하지 않는다.**
- `preview/`: 같은 CAD에서 렌더링한 조립·절개·발사체 이미지. AI 생성 이미지가 아니다.
- `dimensions.svg`: 핵심 치수와 부품 배치도. 단위 mm, 종이 인쇄 축척은 보장하지 않는다.
- `BOM.csv`: 출력/구매 부품과 수량.
- `calibration.csv`: 실제 계량 및 거리 시험 기록용 빈 양식.
- `qa/mesh_report.json`: STL 연결성·닫힌 표면·방향·출력판 외곽 크기 검사.
- `qa/interference_report.json`: 선택한 위치에서의 CAD 교차 체적 검사.
- `qa/tool_clearance_report.json`: 장전 포크 외곽의 작업대/받침 윗면 높이 여유 계산. 손이나 장갑 공간 검증은 아니다.
- `qa/verification_metadata.json`: 검사한 CAD 원본 해시와 검사 범위.
- `build.py`: OpenSCAD를 사용해 STL·미리보기·검사 결과를 재생성하는 스크립트.

## 먼저 출력할 것

1. `10_hole_fit_coupon.stl` — 금속 Ø4 핀과 Ø6 가이드 축의 기본 구멍 끼움 확인.
2. `11_slot_fit_coupon.stl` + `04_upper_pusher.stl` — 슬롯 간극 확인.
3. `08_buoy_100x10.stl` — 모형 한 개를 출력하고 무게를 잰다.
4. 앞의 결과가 적절할 때 본체·데크·슬라이더·지지대를 출력한다.

구멍 쿠폰은 수직 출력 구멍이다. 본체/슬라이더의 **수평 가이드 축 구멍**은 별도로 확인해야 한다. 수평 구멍 처짐과 FDM 수축은 CAD 검사에 반영되지 않는다. 부품을 억지로 끼우거나, 맞지 않는 상태에서 스프링 힘으로 움직이지 않는다.

권장 **출발 설정**: 기구 부품은 PETG, 층 높이 0.2mm, 벽 4~5줄, 상하층 각 5줄 이상, 인필 35~45%. 슬라이더·장전 포크·볼트 주위는 더 많은 벽/국부 인필을 검토한다. 이 설정은 구조 강도 인증값이 아니다. FDM 구멍·오버행·브리지 품질에 맞춰 서포트나 출력 방향을 조정한다.

발사체는 플라스틱만 사용한다. 기본 링 STL은 **속이 찬 외곽 형상**이고 내부 빈 공간은 슬라이서의 낮은 인필로 만든다. 시작값은 벽 3줄, 상하 각 5줄, 인필 10%, 층 0.2mm. 최종 무게는 슬라이서와 저울로 확인한다. CAD 체적을 그대로 실제 저인필 출력물 무게로 해석하지 않는다.

링의 완전 고체 체적은 약 58.6cm³이므로 PLA를 속까지 꽉 채우면 약 73g이 된다(밀도 1.25g/cm³ 가정). 20~30g은 목표이지 확정 출력 무게가 아니다. 목표보다 가벼워도 금속 추를 넣지 않는다. 누수 없이 뜨는지도 별도로 확인한다.

## 스프링은 아직 구매 확정하지 말 것

파란 원통은 스프링이 들어갈 **공간 표시**다. 스프링 STL이 아니며 출력하지 않는다.

- 중앙에 Ø6 가이드 축이 지나간다. 스프링 내경·가이드 축 적합성은 제조사 조건을 따른다.
- 외경 **14mm 이하**의 공간을 예약했다. 실제 압축 중 지름 변화와 가이드 간섭을 확인한다.
- 명목 스프링 자리 길이는 장전 시 **약 32mm**, 완충재 접촉 시 **약 88mm**다.
- 핀 맞춤을 위한 뒤쪽 여유 때문에 자리 길이가 **약 30mm**까지 줄 수 있다. 실제 와셔 두께를 포함해 측정한다.
- 따라서 선택할 스프링은 이 작동 길이 범위와 반복 압축을 제조사가 허용해야 한다. **외경/길이만 맞는 스프링을 넣어서는 안 된다.**
- 자유장 약 88mm는 설계 공간의 기준일 뿐, 해당 제품이 존재하거나 필요한 힘을 낸다는 뜻이 아니다. 필요한 제품이 없으면 원본의 자리 길이·스트로크를 다시 설계한다.
- 강성, 최대 허용 변위, 밀착 높이, 공차, 좌굴, 피로 수명, 출력물·핀·정지부의 허용 하중은 미확정이다. 필요한 스프링 선정에 슬라이더/밀대 질량과 마찰도 포함한다.

**실제 스프링의 데이터시트와 출력물 평가 없이 에너지를 저장하거나 발사하지 않는다.** 스프링이 밀착되는 지점까지 무리하게 압축하지 않는다. 압축 스프링의 가이드/밀착 높이에 관한 [제조사 안내](https://www.leespring.com/learn-about-compression-springs)를 참고한다.

## 금속 부품과 체결

정확한 목록은 `BOM.csv`를 따른다. 볼트 길이는 일반적인 머리/와셔/너트 조합을 가정한 시작값이며 실제 조립에서 확인한다.

- Ø6 **매끈한 가이드 축(연마봉)** 160mm + 샤프트 칼라 2개. M6 전산볼트로 대체하지 않는다.
- M3×30 볼트 8개: 데크 6개, 밀대 2개. 밀대 아래 너트는 깊이 5.2mm 포켓 안의 천장에 당겨 고정된다. 볼트 끝이 슬라이더 바닥 아래로 돌출되면 사용 중지.
- 피치 회전축은 **양쪽 독립 M6 볼트**다. 중앙을 관통하는 긴 볼트는 내부 가이드 축과 충돌하므로 사용하지 않는다.
- 각도 고정은 양쪽 M5 볼트 + 너트 + 넓은 와셔. 한쪽만 고정하지 않는다.
- 두 수직 핀은 Ø4 **금속 핀**이다. 데크와 바닥 구멍을 관통하고 머리는 데크 위에서 걸린다. 머리 밑 길이 약 40mm를 가정했으며, 실제 유효 체결길이/인출 공간을 확인한다.
- Ø4 핀 중 `y=-11`을 해제 핀, `y=+11`을 보조 안전핀으로 구분한다. 좌표의 앞 방향은 본체가 배출하는 +X 방향이다.
- 장전 포크는 전체 90×102×6mm다. 손잡이가 작업대에 닿지 않도록 짧게 배치했다. 사용자의 손·장갑·별도 고정 클램프 공간은 실물로 확인한다.
- 스프링 양 끝에는 가이드 축용 금속 평와셔. Ø14.4 포켓에 들어가는 외경과 실제 두께를 확인한다. 자리 길이 계산은 실측값을 사용한다.
- 완충 블록은 실리콘/우레탄 **6×12×16mm** 두 개의 공간을 예약했다. 1mm가 앞 지지부 홈에 들어간다. 탈락 방지와 충격 흡수 성능은 미검증이다. 딱딱한 PLA 블록으로 대체하면 완충 기능이 없다.

## 무하중 조립 순서

**이 단계 전체에서 스프링은 설치하지 않는다. 전원/서보도 연결하지 않는다.**

1. 출력물을 정리하고 균열, 층 분리, 휨을 확인한다. 구멍을 억지로 누르지 않는다.
2. 본체 바닥 너트 포켓에 데크용 M3 너트 6개를 넣는다. 옆벽 안쪽에는 M6/M5 너트를 넣는다.
3. 하부 슬라이더 바닥에 M3 너트 2개를 넣고 가이드 축에 끼운다. 축을 본체 앞/뒤 지지 구멍에 끼워 칼라로 이탈을 막는다.
4. 데크를 얹고, 뒤집혀 출력된 상부 밀대를 정상 방향으로 돌려 두 연결부를 슬롯에 넣는다. 밀대와 하부 슬라이더를 M3×30 두 개로 체결한다.
5. 데크를 M3×30 여섯 개로 닫는다. 이동 전 구간에서 나사 끝·너트·가이드 축·슬롯이 닿지 않는지 확인한다.
6. 완충재 자리와 하부 정지면을 확인한다. 밀대를 앞으로 움직여 정지면과 슬롯 끝의 순서를 확인한다. **밀대가 슬롯 끝에 먼저 부딪히면 안 된다.**
7. 밀대를 장전 위치로 옮겨 수직 핀 두 개가 데크–슬라이더–바닥을 모두 지나가는지 확인한다.
8. 지지판 두 개를 바닥 소켓에 넣어 M4 볼트로 체결한다.
9. 본체와 지지판 사이에 6mm 스페이서를 넣고 양쪽 M6 피치 볼트를 체결한다. 선택한 각도 구멍에는 양쪽 M5 볼트를 체결한다.
10. 받침을 별도 시험판에 고정한다. 흔들림, 볼트 풀림, 핀을 위로 뽑을 공간을 확인한다.
11. 장전 포크로 무하중 왕복을 연습한다. 포크를 위에서 밀대 주위에 끼워 뒤로 당긴 뒤 핀 두 개를 넣고, 포크의 힘을 풀어 핀이 잡는 것을 확인한 다음 포크를 위로 들어 제거한다.
12. 모형을 올려 가이드와 밀대가 걸리지 않는지 확인한다. 모형은 처음 약 3mm 앞쪽으로 돌출되며 중심은 충분히 데크 위에 있다. 출력 오차로 걸리면 수정한다.

## 에너지가 있는 시험으로 넘어가기 전

아래 항목은 아직 완료하지 않았다. 기구 담당자/지도자와 검토해야 한다.

- 선정한 스프링의 허용 하중·밀착 높이와 실제 장전 길이 검토.
- 핀, 핀을 받치는 출력물, 장전 포크, 밀대, 가이드 축 지지부, 완충/정지부의 강도 및 반복 내구 평가.
- 완충재의 확실한 탈락 방지, 정지 충격에 대한 별도 금속 보강 필요 여부 결정.
- 장전 핀의 불완전 삽입/끼임/인출력 확인. 핀이 부하를 받을 때 원활히 빠질 것이라고 가정하지 않는다.
- 각도와 압축량은 **스프링 에너지를 제거한 상태에서** 변경한다.
- 손/얼굴을 배출구·밀대·슬롯 가까이에 두지 않고, 사방 이탈을 받는 포획함과 보호구를 갖춘다.
- 장전 포크가 분리되어 있고, 모형 외 부품이 비행할 수 없는지 확인한다.
- 취소/고장 시 갑자기 핀을 빼지 않고, 기구 담당자가 검토한 제어된 에너지 해제 방법을 마련한다. 전원을 꺼도 스프링 에너지는 사라지지 않는다.
- 본 설계에는 자동발사 소프트웨어, 독립 안전 제어기, 인터록 검증이 없다.

## 각도와 거리 검증

20~60cm는 **시험 목표**다. 해당 구간을 각도만으로 모두 달성한다고 보장하지 않는다. 먼저 같은 모형·같은 압축량·같은 설치면에서 반복 측정한다.

이 설계는 높이를 낮추기 위해 본체 뒤쪽에 피치 축을 둔다. 따라서 각도를 바꾸면 **출구 높이도 변한다.** 출구 중앙의 데크 표면 기준 CAD 높이는 설치 바닥에서

`h_mm = 36 + 144*sin(angle) + 20*cos(angle)`

이다. 발사체 중심은 이보다 약 5mm 높고, 모형이 데크를 떠나는 실제 위치는 실험에서 확인해야 한다. 시험판 두께, 별도 받침, 수면 높이는 추가 보정한다. 출구와 착지면 높이가 같은 경우에만 단순 `R=v²*sin(2θ)/g`를 적용할 수 있다. [OpenStax 설명](https://openstax.org/books/physics/pages/5-3-projectile-motion)

각 각도에서 처음 접촉하는 위치를 여러 번 기록하고 평균뿐 아니라 산포도 확인한다. 튕김/굴러간 최종 위치를 사거리로 기록하지 않는다. 링의 자세 변화·미끄럼·마찰 때문에 포물선 식과 다를 수 있다. 각도로 부족하면 스프링/압축량을 다시 검토하며, 임의로 강한 스프링을 추가하지 않는다.

## 변경 / 재생성

OpenSCAD에서 `launcher.scad`를 열고 `part` 값을 바꾸면 개별 부품을 볼 수 있다. F6으로 렌더한 뒤 STL로 내보낸다. `pitch`는 미리보기 각도, `travel`은 이동 상태다. 개별 STL은 출력 방향으로 정렬되어 있다. XY 원점이 음수인 파일은 슬라이서의 자동 중앙 배치를 사용한다.

```powershell
python .\build.py --checks --renders
```

Python 실행 파일과 OpenSCAD 설치 경로가 다르면 실행 경로 또는 `--cad`를 변경한다. 표준 라이브러리만 사용한다. 생성 파일은 같은 폴더의 `stl`, `qa`, `preview`에 갱신된다.

## 검증 범위와 한계

STL의 닫힌 메시, 일관된 면 방향, 연결성, 220mm 출력판 가정의 외곽 크기를 검사한다. 명목 슬라이더 위치, 선택한 각도 및 중간 각도의 **강체 CAD 간섭**을 검사한다. 간섭 계산은 기능과 무관한 글자 각인을 생략하고 원형 세그먼트 수를 낮춘 별도 형상으로 수행한다. 이는 인쇄 메시 그대로의 모든 미세 간극을 검증하는 검사는 아니다. 이 검사는 출력 강도, 마찰, 스프링 작동, 나사산/너트 공차, 체결력, 동적 휨, 물샘, 전 구간 연속 충돌 및 실제 사거리를 검증하지 않는다.

금속 핀/볼트/칼라/스프링은 렌더링에 단순화되어 보인다. 구매 부품의 실제 머리·나사산·인출 길이는 데이터시트와 실물로 확인한다. STL은 밀폐된 다면체라는 뜻에서 watertight여도 **프린트가 물을 막는다는 뜻은 아니다.** [Prusa 수밀 출력 안내](https://help.prusa3d.com/article/watertight-prints_112324)

FDM의 끼움 공차와 방향별 특성은 [Prusa 설계 안내](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)를 참고한다.
