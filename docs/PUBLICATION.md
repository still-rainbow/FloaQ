# 공개 준비 기록

이 사본은 소스 정리와 설정 분리를 수행한 포트폴리오 스냅샷입니다.
원본 프로젝트 전체를 독립 재작성한 결과가 아닙니다.

## 포함

- 웹·백엔드·AI·엣지 소스와 기존 자동 테스트
- 장치 메시지 계약과 데이터베이스 스키마
- 로컬 설정 예제와 OpenSCAD 원본

## 제외

- 기존 Git 이력, 교육 실습 및 내부 CI 설정
- 실제 환경 파일, 기관 내부 주소, 개인 실험·인수인계 자료
- 모델 가중치, 학습 데이터, 촬영 영상, 실측 교정 파일
- 빌드 산출물, 의존성 폴더, 생성된 STL·미리보기

## 변경

- 저장소 경로를 ai/backend/frontend/iot/infra/database/hardware로 재구성
- 경로 변경에 따른 스키마와 펌웨어 참조 수정
- 프론트 개발 주소를 localhost 기본값 및 환경변수로 분리
- 특정 기관의 LLM 게이트웨이를 제거하고 선택형 호환 API 설정으로 일반화
- prod 프로파일에서 공개된 예제 계정 생성 비활성화
- PowerShell 스크립트의 UTF-8 BOM 유지
- 비밀값·대용량 파일 점검 스크립트 및 검증 명령 추가
- 비공개 이슈 트래커 링크를 이슈 번호 텍스트로 바꾸고 재유입 점검 추가
- 기구 문서의 개인 이름과 AI 설정·문서의 개인 경로를 일반화
- 커밋 작성자·커미터 이메일을 GitHub noreply 주소로 통일

2026-10-06 저장소 소유자가 공개 권한을 확인했다고 알려 Public 공개를 유지하기로 했습니다.
이 상태는 소유자의 확인에 따른 기록이며, 코드 점검으로 공개 권한을 판정한 것은 아닙니다.
원본 보존 및 변경 내역의 상세 manifest는 공개 저장소 밖에 보관합니다.
