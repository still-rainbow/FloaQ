## 사본에서 바로잡은 기존 검사 불일치

- PiIngestServiceTest의 생성자에 현재 필요한 OceanAt 의존성을 제공했습니다.
- 서보 검사와 Pi README를 작업 중인 보정값(되감기 1.0초)에 맞췄습니다.
  서보 구동 코드는 원본 작업 상태를 유지했고 실장비를 구동하지 않았습니다.
- 해양 표시 검사는 이미 제거된 조업 표의 저체온 행이 없음을 확인하도록 맞췄습니다.

## 실행 범위

Python 검증은 별도 Python 3.12 CPU 환경에서 실행했습니다.
Pi 실제 환경(Python 3.13.5), Jetson 실제 환경(Python 3.10.12) 설치를 대체하지 않습니다.
백엔드 unitTest는 PostgreSQL·TimescaleDB·Redis가 필요한 4개 통합 테스트 클래스를 제외합니다.
전체 테스트는 인프라를 준비한 다음 gradlew test로 실행해야 합니다.
GPU 학습·카메라·GPIO·서보·무선 송수신·CAD 렌더와 실제 운영 배포는 실행하지 않았습니다.
GitHub Actions 파일은 추가했지만 GitHub에서 워크플로를 실행한 것은 아닙니다.

브라우저 번들 크기 경고와 테스트용 HTTP 클라이언트 deprecation 경고가 남아 있습니다.
파일 점검은 알려진 패턴 기반이며 기관 규정 준수나 모든 비밀정보 부재를 보증하지 않습니다.
