# DES-37 발사 메커니즘 방식 결정

- Jira: floaq-125
- 선행: [DES-33 부품 목록](IoT_REVIEW_DES-33_부품선정.md)
- 작성일: 2026-09-09 · 수정일: 2026-09-10
- 상태: 방식 확정 · **스프링 실측 전 제작 중단**
- 대상: 소형선박용 구명 부유체 시연 장치

## 1. 요구사항

- 목표 사거리 20~60 cm. 실험 목표이며 설계만으로 보장하지 않는다.
- 발사체는 금속 추가 없는 경량 비통신 모형.
- 초기 버전은 수동 장전하되 같은 본체에 서보 해제를 추가할 수 있어야 한다.
- 독립 안전 핀으로 우발 해제를 방지한다.
- 고압·고에너지 부품을 전제하지 않는다.

## 2. 후보 비교

정성 평가이며 팀 승인이나 성능 측정값이 아니다. 5점이 가장 유리하다.

| 평가 항목 | 가중치 | 압축공기 | 압축 스프링 | 모터 직접 구동 |
|---|---:|---:|---:|---:|
| 부품 조달·제작 난이도 | 25% | 2 | 4 | 3 |
| 에너지 상태의 가시성 | 20% | 2 | 4 | 4 |
| 소형화·중량 | 15% | 3 | 4 | 3 |
| 반복 동작의 단순성 | 15% | 3 | 4 | 3 |
| 제어 확장성 | 15% | 4 | 4 | 5 |
| 누설·과압 등 부가 위험 | 10% | 1 | 3 | 4 |
| **가중 합계** | 100% | 2.50 | **3.90** | 3.60 |

압축공기는 탱크·레귤레이터·배관과 누설 관리가 필요해 검증 범위가 과하다. 모터 직접 구동은 위치 제어에 유리하지만 순간 에너지 전달을 위한 추가 감속·축적 기구가 필요하다. 압축 스프링은 구조가 단순하고 장전 상태를 눈으로 확인할 수 있으며, 잠금 핀이 하중을 지지하고 서보는 해제만 담당하도록 분리할 수 있다.

## 3. 결정

**압축 스프링이 슬라이더와 직선 밀대를 전진시키는 방식을 채택한다.** 저에너지 조건은 스프링 사양과 압축량으로 확보한다(§4).

```mermaid
flowchart LR
    S[압축 스프링] --> L[하부 슬라이더]
    L --> P[상부 직선 밀대]
    P --> B[비통신 링 모형]
    K[금속 잠금 핀] -. 장전 상태 유지 .-> L
    V[서보 또는 수동 조작] -. 핀 해제 .-> K
```

| 항목 | 값 |
|---|---|
| 발사체 가이드 | 데크 위 직선 이동 |
| 가이드 축 | Ø6×200mm 봉재 절단 (목표 길이 실측 후 확정) |
| 피치 축 | Ø6×100mm 봉재 2개 |
| 잠금·안전 핀 | Ø4×100mm 봉재 절단, 2개 (유효 길이 실측 후 확정) |
| 명목 밀대 이동량 | **미확정** — 스프링 밀착높이 실측 후 결정 |
| 스프링 수용부 외경 | 최대 Ø14 mm — §4 참조, 재검토 필요 |
| 스프링 강성 | **실측 대기** (추정 6~15 N/mm) |
| 장전 | 수동 |
| 해제 | 수동 기준. 서보 3개 중 축별 배분 후 자동화 재검토 |

채택 이유는 단순성, 장전 상태 육안 확인, 단계적 자동화, 현재 제작 여건이다. 재검토 조건은 20~60 cm 목표 실패, 핀 인출력 과다, 출력물 내구성 부족, §4 실측이 에너지 초과를 확인하는 경우다.

## 4. 스프링 정량 검토 — 제작 차단 사유

주문 스프링 옵션은 자유장 60mm, **선경 2.0mm**, 외경 13mm다. 이 규격에서 추정 강성은 다음과 같다.

계산 조건: G = 79.3 GPa, 평균직경 Dm = 13 − 2 = 11 mm, 압축량 36 mm 기준. 활동권수 미확인이므로 범위로 제시한다.

| 활동권수 | 강성 k | 36mm 압축 하중 | 저장 에너지 | 25 g 링 초속 |
|---:|---:|---:|---:|---:|
| 8 | 14.9 N/mm | 536 N (54.7 kgf) | 9.7 J | 27.8 m/s |
| 12 | 9.9 N/mm | 358 N (36.4 kgf) | 6.4 J | 22.7 m/s |
| 16 | 7.5 N/mm | 268 N (27.3 kgf) | 4.8 J | 19.6 m/s |
| 20 | 6.0 N/mm | 215 N (21.9 kgf) | 3.9 J | 17.6 m/s |

### 판단

1. **에너지가 시연 범위를 벗어난다.** 목표 사거리는 20~60 cm인데 초속 18~28 m/s는 두 자릿수 차이다. 3.9~9.7 J은 교육·시연 장치로 취급하는 통상 기준(1 J 내외)의 수 배다. §1의 "고에너지 부품을 전제하지 않는다"는 요구사항과 충돌한다.
2. **압축률이 과하다.** 자유장 60mm에 36mm 압축은 **60%**다. 압축 스프링의 권장 작동 압축량은 통상 자유장의 30~40%로, 60%는 밀착 높이 도달 또는 영구 변형(set) 위험 구간이다. 선경 2.0mm에서 총권수가 12면 밀착 높이가 24mm이므로 36mm 압축은 **매 발사가 밀착 충돌**이 된다.
3. **좌굴 위험이 있다.** 자유장 / 평균직경 = 60 / 11 = 5.45로 양단 자유 지지 시 좌굴 임계 근방이다. 가이드가 있으면 완화되지만 측면 마찰이 생긴다.
4. **수용부 간섭 우려.** 수용부 최대 Ø14mm에 외경 13mm는 측당 여유 0.5mm다. 고압축 시 코일 직경 증가와 좌굴을 흡수하기 어렵다.

### 조치

- 스프링 실측(자유장·선경·외경·총권수·활동권수·밀착높이)과 하중–변위 직접 측정을 최우선으로 한다.
- **실측 전에 스프링을 장치에 넣지 않는다.**
- 최대 허용 압축량을 먼저 확정하고 명목 밀대 이동량을 그 값 이하로 설정한다.
- 목표 사거리를 유지하려면 압축량을 수 mm 수준으로 줄이거나, 선경이 작은 스프링을 별도 조달한다. 후자가 유력하다.
- 5개입 중 1개를 파괴 시험용으로 분리해 둔다.
- 수용부 내경을 재검토한다.

## 5. 기구 부품 배정

626ZZ(6×19×6) 10개와 Ø6×100mm 봉재 2개는 피치 축 하중 지지에 대응한다. 4인치 회전 베어링 1개는 yaw 받침 후보다.

623ZZ(3×10×4) 10개는 내경 3mm이지만 **Ø3 축재가 주문 목록에 없다.** 용도를 특정하거나 Ø3 축재를 조달하지 않으면 사용할 수 없다.

칼라 규격·수량, 축 공차, 체결 패턴을 확인한 뒤 사용한다.

## 6. 범위

- 포함: 스프링·슬라이더·밀대·잠금 핀 직선 발사, 수동·자동 해제 공용 프레임, 독립 안전 핀과 yaw/pitch 결합면
- 제외: 자동 장전, 실시간 압축량 제어, 구조용 인증·선박 탑재 승인, 사람·실제 구명튜브 대상 성능 보증

## 7. 위험 통제

| 위험 | 통제 |
|---|---|
| 장전 중 우발 해제 | 잠금 핀 + 독립 안전 핀, 2인 1조 장전 |
| 핀 끼임 | 무스프링 정렬·인출력 측정. 큰 서보 힘으로 강제 해제 금지 |
| 하드 스톱 충돌 | 완충재 설치, 슬롯 끝보다 완충부가 먼저 작동하는지 확인 |
| **과도한 에너지** | §4 실측 완료 전 장착 금지. 저에너지 조건부터 단계 시험 |
| 스프링 밀착 충돌 | 밀착높이 실측 후 압축량 제한을 기구적으로 고정 |
| 출력물 파손 | 매 시험 전 균열·층분리·체결부 점검 |
