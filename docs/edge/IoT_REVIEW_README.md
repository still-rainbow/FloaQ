## 최우선 차단 항목

주문 스프링(자유장 60mm, **선경 2.0mm**, 외경 13mm)의 추정 강성은 **6~15 N/mm**로, 저장 에너지가 36mm 압축 시 **3.9~9.7 J**이다. 목표 사거리 20~60cm와 두 자릿수 차이이며, 잠금 핀 인출에 필요한 토크도 MG996R 정격을 초과할 수 있다. 근거와 수치는 DES-37 §4, DES-38 §3에 있다.

**스프링 실측(자유장·선경·외경·총권수·밀착높이·하중변위)이 나머지 기구 결정 전부를 막고 있다.** 실측 전에 스프링을 장치에 넣지 않는다.

## 공통 전제

각 문서에서 반복하지 않는다.

- 교육·시연용 시제품이며 실제 인명 구조 장비가 아니다.
- CAD 검증은 형상과 정적 간섭만 확인한 것이며 강도·내구·사거리·수밀성을 보증하지 않는다.
- 설계값은 실물 측정 결과에 따라 변경된다. 미실측값을 확정값으로 인용하지 않는다.
- 실제 스프링 장착 전에 끼움 시험편과 무스프링 조립을 먼저 검증한다.
- 사람·동물·차량·유리·전자장비를 향해 발사하지 않는다. 보호구와 전 방향 포획함을 사용한다.
- 전원과 무관하게 스프링 에너지가 남는다. 모든 작업 절차에 잔류 에너지 확인을 포함한다.
- **부표는 2종이다.** 발사되는 것은 비통신 링 모형(DES-39), GPS·LoRa·버튼·LED를 탑재한 추적 부표는 실물 크기로 별도 제작하며 **발사하지 않는다.** 문서·발표에서 두 물건을 섞지 않는다.
- 선박 측과 추적 부표는 전기적으로 분리된 독립 계통이다. GND도 연결하지 않는다.
