# DES-39 시연용 발사체 모형 설계 (통신 모듈 미탑재)

- Jira: floaq-127
- 선행 대상: IOT-17 시연용 비통신 모형 운용
- 작성일: 2026-09-09 · 수정일: 2026-09-10
- 상태: 형상 확정 · 출력·부력·반복 발사 검증 전

실제 구명튜브 대신 발사 장치의 조립·조준·저거리 발사 시연에 쓸 비통신 모형의 형상과 제작 조건을 정의한다.

## 1. 설계 사양

| 항목 | 값 |
|---|---|
| 형상 | 평면 링 |
| 외경 / 내경 / 두께 | 100 / 50 / 10 mm |
| 가장자리 | 0.8 mm 모따기 |
| 제작 | FDM 3D 프린팅 |
| 시작 재료 | PLA 또는 PETG, 실제 조건 기록 |
| 시작 설정 | 0.2 mm 층, 벽 3줄, 상·하 5층, 인필 10% |
| 목표 질량 | 20~30 g, 출력 후 실측 |
| 통신·전자부품 | 없음 |
| 금속 추 | 사용 금지 |

목표 질량은 설계 의도이며 보증값이 아니다. 위 설정에서 실효 재료 부피는 약 20.6 cm³이므로 PLA 25.5 g / PETG 26.1 g이 예상되며 목표 범위와 정합한다. 재료와 슬라이서 경로에 따라 달라지므로 모든 시험에서 실측한다.

## 2. 선택 근거

- 실제 구명 부유체의 시각적 특징을 단순화한다.
- 중앙 구멍으로 질량을 낮추고 회수하기 쉽다.
- 회전 대칭 외곽은 가이드에 반복 정렬하기 쉽다.
- 단일 출력 부품이라 전자부품·배터리 파손 위험이 없고, 금속 추가 없어 고밀도 부품 비행 위험을 줄인다.

## 3. 시스템 안에서의 위치

- [DES-33](IoT_REVIEW_DES-33_부품선정.md)의 60cm RC 선박은 시연 플랫폼이고, 이 링은 별도 제작할 발사체다.
- '비통신'은 링 모형에만 해당한다. Jetson–Pi 추론·제어 통신이나 E22 송수신 시연을 제외한다는 뜻이 아니다.
- **부표는 2종이다 (2026-09-10 확정).** 이 문서의 링 모형은 발사되는 쪽이고, GPS·LoRa·버튼·LED를 탑재하는 **추적 부표는 실제 크기로 별도 제작하며 발사하지 않는다.** 제어보드는 Arduino UNO다([DES-33 §1](IoT_REVIEW_DES-33_부품선정.md), 회로 [DES-34 §12](IoT_REVIEW_DES-34_회로도.md), 전원 [DES-35 §3.2](IoT_REVIEW_DES-35_전원설계.md)).
- 따라서 **이 링에는 전자부품·배터리·보드를 일절 탑재하지 않는다.** 주문 GPS·LoRa·IMU는 전량 선박 측과 추적 부표로 배분된다([DES-33 §4](IoT_REVIEW_DES-33_부품선정.md)).
- 발표에서 두 부표를 구분해 설명해야 한다. "발사된 물체가 위치를 송신한다"고 오인되면 시연 내용과 다르다.
- 링 출력물은 주문 목록에 없다. 자체 출력 대상이다.
- 60cm 선박의 탑재 하중은 미확인이다. 발사대·보드·전원·케이스 총중량과 고정 위치를 확인하기 전 선박에 장착 가능하다고 판단하지 않는다.

## 4. 발사 장치 인터페이스

```text
측면 가이드 안쪽 폭 108 mm
┌──────────────────────────────────┐
│      링 외경 100 mm              │
│    ┌──────────────────────┐      │
│    │      내경 50 mm      │      │
│    └──────────────────────┘      │
└──────────────────────────────────┘
좌우 명목 여유: 각 4 mm
```

- 링의 평평한 면을 데크에 놓고 직선 밀대가 뒤쪽 외곽을 민다.
- 출력 변형과 표면 거칠기 때문에 실물 간극은 달라질 수 있다.
- 걸린 상태에서 억지로 발사하지 않는다.

## 5. 스프링 의존성

[DES-37 §4](IoT_REVIEW_DES-37_발사메커니즘.md)에서 주문 스프링의 저장 에너지가 3.9~9.7 J로 추정됐다. 25 g 링에 전달되면 초속 18~28 m/s가 되어 시연 조건을 크게 벗어난다.

**링 질량이나 인필을 바꿔 이 불일치를 해결하지 않는다.** 스프링 측에서 압축량 제한 또는 저강성 스프링 조달로 해결한 뒤 거리 시험으로 연결한다. 그때까지 §6 '저에너지 발사' 항목을 수행하지 않는다.

## 6. 제작 절차

1. 슬라이서 단위를 mm로 확인하고 자동 확대·축소를 끈다.
2. 넓은 링 면을 출력판에 배치한다.
3. 시작 조건으로 1개만 출력하고 치수와 질량을 측정한다.
4. 들뜸, 균열, 층분리, 날카로운 버를 확인한다.
5. 데크 위에서 스프링 없이 손으로 밀어 걸림과 이탈을 확인한다.
6. 양면에 `DEMO ONLY`와 식별 번호를 표시한다.
7. 재출력 시 재료·설정·질량과 변경 이유를 기록한다.

## 7. 합격 기준

| 검사 | 방법 | 합격 조건 |
|---|---|---|
| 외경 | 캘리퍼 | 가이드 안에서 좌우 걸림 없이 이동 |
| 내경·두께 | 캘리퍼 | 형상 식별 가능, 균열 없음 |
| 질량 | 0.1 g 저울 | 실측값 기록, 금속 추 없음 |
| 표면 | 육안·장갑 낀 손 | 날카로운 버·층분리 없음 |
| 정적 이동 | 스프링 없이 왕복 | 데크 전 구간 걸림 없음 |
| 저에너지 발사 | 포획함 내부 시험 | 부품 이탈·파손 없이 회수 가능 (§5 선행) |

## 8. 안전

- 실제 구명 장비로 오인하지 않도록 `DEMO ONLY`를 영구 표시한다.
- 파손·균열·변형 또는 수분 침투가 확인된 모형은 재사용하지 않는다.
- 질량을 맞추기 위해 금속 볼트·너트·추를 삽입하지 않는다.
