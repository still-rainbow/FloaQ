# 시연 사항

시연 날 무엇을 어떤 순서로 켜고, 무엇을 조심하고, 무엇이 이상하게 보여도 정상인지 정리했다.
통신 구조 전체는 [communication.md](communication.md) 를 본다.

- 기준: 브랜치 `dev-iot`, 2026-09-23
- 🔴 = 안 지키면 다치거나 시연이 멈춘다, ⚠ = 이상하게 보이지만 이유가 있다

---

## 1. 켜는 순서

**0) 코드 받기** — Pi 와 Jetson 둘 다

```bash
git pull
```

**1) Pi 창 1 — 브로커**

```bash
cd iot/pi
./scripts/dev.sh broker
```

**2) Pi 창 2 — 오케스트레이터 (실전, 발사함)**

```bash
./scripts/dev.sh close        # 앞 사고가 열려 있으면 닫는다 (열려 있으면 새 탐지를 안 받는다)
./scripts/dev.sh pi --servos --lora serial --imu i2c --report udp --report-host <OpenCPN PC IP>
```

**3) Jetson**

```bash
cd iot/jetson
./scripts/live.sh <PI IP> --aim-detect
```

Pi 를 Jetson 보다 **먼저** 띄운다. Jetson 은 Pi 에서 배 ID 를 받아야 뜬다.

### 조준만 볼 때 (발사 안 함)

```bash
./scripts/dev.sh aim                          # Pi. CH2(발사) 채널을 아예 안 연다
./scripts/live.sh <PI IP> --aim               # Jetson. 사고·사진·신고를 안 만든다
```

---

## 2. 🔴 안전

- **`dev.sh pi --servos` 는 기본이 발사다.** 좌우 카메라가 사람을 잡아 조준이 **한 번** 오면 **0.3초 뒤**
  부표가 나간다. 확인 버튼 같은 것은 없다. 띄우기 전에 발사관 앞 3m 안을 비운다.
- 조준만 보려면 반드시 `dev.sh aim` 이나 `--no-fire` 를 쓴다.
- 발사는 **프로세스당 한 번** 이다. 다시 쏘려면 Pi 를 껐다 켠다.
- 수동 서보 도구(`2servo.py`)와 오케스트레이터를 **동시에 돌리지 않는다.** 같은 서보 보드를 잡는다.
  `2servo.py --ch2 plus` 는 실제로 핀을 당긴다.

---

## 3. 발사관 기본값

| 항목 | 값 | 바꾸는 법 |
|---|---|---|
| 켜자마자 자세 | CH0 120(왼쪽), CH1 150(아래) — 이 자세로는 안 쏜다 | `--start-ch0`, `--start-ch1` |
| 몇 번 안정되면 쏘나 | 1번 (첫 조준에 바로) | `--fire-stable-count` |
| 쏘기 전 대기 | 0.3초 (서보가 도착할 시간) | `--fire-settle-seconds` |
| CH2 정방향 발사 | 기본 1.3초, 최대 5초, throttle +1.0 | `--ch2-max-seconds` |
| CH2 역방향 감기 | 중립 0.5초 뒤 1.2초, throttle -1.0, 이후 중립 | 고정값 |
| 수평 | CH1 140 (09-23 실측). 숫자가 작을수록 위를 본다 | `floaq/config.py` `PITCH_CAL` |
| 좌우 | 명령값 90 초과가 왼쪽 (09-23 실측) | `--yaw-cal` |

Pi 기동 로그에서 확인:

```
start pose CH0 120.0, CH1 150.0
🔴 실발사 무장. 조준이 1회 안정되면 부표가 나간다
```

## 4. 조준·거리

- Jetson 로그의 `range=` 는 **발사관 회전축** 에서 잰 거리다. **배 중심에서 잰 거리보다 27cm 짧게** 나오는 게 정상이다.
  거리를 줄자로 확인할 때는 발사관 회전축 바로 아래 바닥부터 잰다.
- 좌우 카메라 **둘 다** 사람을 잡아야 조준이 나간다. 5초 상태줄의 `본것` 에 L·R 둘 다 `3`(사람)이 보여야 한다.
  한쪽만 보이면 미리보기에 `person missing in L/R` 이 뜬다.
- 3m 보다 멀면 조준을 안 보낸다(`range rejected`).
- 발사각은 거리로 계산한다. 가까우면 숙이고 멀면 든다. 맞추는 곳은 Jetson `configs/stereo_targeting.yaml` 의 두 숫자뿐이다.

  | 값 | 지금 | 뜻 |
  |---|---|---|
  | `near_m` | 0.20 | 가장 숙여(−10°) 쐈을 때 떨어지는 거리 |
  | `far_m` | 0.32 | 가장 들어(25°) 쐈을 때 떨어지는 거리 |

  **짧게 떨어지면 `far_m` 을 줄이고, 넘어가면 늘린다.** 고친 뒤 `live.sh` 를 다시 띄운다(Pi 는 그대로).
- ⚠ Pi 와 Jetson 시계가 2초 넘게 어긋나면 조준이 **전부 조용히** 버려진다. Jetson 은 `live.sh` 를 켤 때 Pi 시계에 맞춘다.

## 5. 부표

### 5.1 지금 방식

- 부표는 **가짜 GPS** 로 쓴다(`iot/buoy/buoy_tx/buoy_tx.ino` `FAKE_GPS 1`). 진짜 GPS 를 안 붙인다.
- 부표 전원은 **미리 켜지 않는다.** 발사할 때 켠다.
- 켜지면 **35.05 / 129.10** 에서 출발해 동쪽으로 초속 약 0.27m 씩 흐르는 좌표를 1초마다 보낸다.
- Pi 기동 로그의 `부표 LoRa /dev/ttyAMA0 @9600  ship_tag=0x64` 에서 태그가 **0x64** 여야 한다.
  배를 새로 등록했으면 태그가 바뀌므로 부표를 다시 굽는다(태그 구하는 법은 `buoy_tx.ino` 머리 주석).
- 사고가 열려 있어야 부표 위치가 기록된다. 사고가 없을 때 온 쪽지는 버리는 게 정상이다.

### 5.2 ⚠ 화면에서 이상하게 보일 수 있는 것

**① 부표가 배에서 멀리 떨어져 보인다**

Pi 의 가짜 배 GPS 는 같은 35.05 / 129.10 에서 출발하지만 **8노트(초속 4.1m)로 동쪽** 으로 계속 간다.
부표는 켤 때마다 출발점에서 시작하므로, Pi 를 켠 지 오래될수록 부표가 배 **뒤쪽(서쪽)** 에 찍힌다.

| Pi 를 켜고 부표를 켜기까지 | 부표가 배에서 떨어진 거리 |
|---|---|
| 1분 | 약 250m |
| 5분 | 약 1.2km |
| 10분 | 약 2.5km |

대처: Pi 를 켠 직후에 시연하거나, Pi 가짜 배를 멈춰 세운다(아래 §7, 아직 미적용).

**② 관제 웹에 부표가 "신호 끊김" 으로 뜬다**

가짜 GPS 모드의 부표 시각은 **"펌웨어를 구운 시각 + 켜진 뒤 흐른 시간"** 이다(`buoy_tx.ino:562`).
굽고 나서 한참 뒤에 켜면 그만큼 **과거 시각** 이 찍힌다. 관제 웹은 부표 시각이 60초보다 오래되면
"신호 끊김" 으로 표시한다(`frontend/apps/web/src/lib/api/accidents.ts`).
배 안의 Pi·키오스크는 받은 시각으로 판단하므로 영향이 적다.

- 예: 오전 10시에 굽고 오후 2시에 켜면 부표 시각이 4시간 전이다 → 웹에서 계속 "신호 끊김"
- 구운 PC 의 시계가 틀려도 그만큼 틀린다

대처: 시연 직전에 굽는다(굽고 나서 켜기까지 짧을수록 좋다). 근본 대처는 §7.

**③ 부표를 껐다 켜면 한동안 위치가 안 쌓인다**

껐다 켜면 부표 시각이 다시 "구운 시각 + 0초" 부터 센다. **같은 사고 안에서** 이미 받은 시각과 겹치는
쪽지는 중복으로 조용히 버려지고, 60초 뒤 "통신 두절" 이 기록될 수 있다. 시연 중에는 부표를 껐다 켜지 않는다.

## 6. 확인할 로그

| 무엇 | 어디서 | 정상이면 |
|---|---|---|
| 브로커 | Pi 로그 | `브로커 접속 localhost:1883` |
| 발사 무장 | Pi 기동 로그 | `🔴 실발사 무장. 조준이 1회 안정되면 부표가 나간다` |
| 조준 수신 | Pi 로그 | `aim yaw=…→CH0 …, pitch=…→CH1 …` |
| 발사 | Pi 로그 | `AUTO FIRE ARMED: … settle 0.3s …` → `AUTO FIRE COMPLETE` |
| 카메라 | Jetson 5초 상태줄 | `본것` 에 L·R 둘 다 `3` |
| 조준 송신 | Jetson 로그 | `sent=True` |
| LoRa 설정 | Pi 기동 로그 | `ship_tag=0x64` |
| LoRa 수신 | Pi 종료 때 `LoRa 링크 통계` | `ok` 가 오른다. `foreign` 만 오르면 태그 불일치 |
| 서버 전송 | Pi 로그 `floaq.sync` | `… N행 전송 (inserted …)` |

## 7. 아직 안 고친 것 (제안)

| 문제 | 제안 | 효과 |
|---|---|---|
| §5.2 ① 부표가 배에서 멀리 | Pi 가짜 배 속도를 인자로 빼고 시연 기본을 0 으로 둔다 | 부표가 배 옆 출발점에서 시작한다 |
| §5.2 ②·③ 부표 시각 | Pi 가 부표 시각과 받은 시각이 크게(예: 2분 이상) 다르면 **받은 시각으로 바꿔 기록** 한다 | 웹 "신호 끊김" 과 재부팅 중복이 둘 다 사라진다. 진짜 GPS 를 붙여도 시각이 틀린 쪽지를 막는다 |
